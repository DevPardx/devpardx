### Raíz &nbsp;·&nbsp; `SaaS / Real Estate`

A real estate platform that connects agents with tenants directly, without intermediaries.

> **■ Problem** — People looking to rent or buy have no reliable, trustworthy place to do it. Facebook Marketplace and WhatsApp groups aren't built for this, and closing a deal through them is painful.
>
> **■ Decisions** — Server Components and Server Actions instead of an intermediate API. Availability computed in PostgreSQL and cached in Redis. Schema-first data layer with Drizzle.
>
> **■ Result** — In production for 6 months, serving Salvadoran users and listing hundreds of properties with sub-200ms response times.

### Meeti &nbsp;·&nbsp; `Meetups / Tech`

A social platform for the tech community — create communities, run meetups in person or remote, and discuss what's actually happening in software.

> **■ Problem** — Tech professionals have no reliable space to discover local and remote events, organize meetups, and join real conversations without scattered platforms and spam-filled groups.
>
> **■ Decisions** — Better Auth for social, email, and password logins. Vercel AI SDK wired to the database through a deliberately narrow, permissioned surface.
>
> **■ Result** — 150+ developers creating and joining communities, with steady organic growth.

### CashTrackr &nbsp;·&nbsp; `SaaS / Finance`

Personal finance and budgeting SaaS with AI-powered receipt parsing and automated expense entry.

> **■ Problem** — Tracking expenses by hand is tedious, categorization is inconsistent, and scattered spending data makes real financial insight nearly impossible.
>
> **■ Decisions** — Laravel and Inertia for the application shell. Stripe for payments and subscriptions. Claude API for receipt parsing and expense categorization. Eloquent over PostgreSQL for persistence.
>
> **■ Result** — Users report a 40% reduction in expense-tracking time, with thousands of transactions processed monthly.
